## ✨ Description
회원가입 중복 확인 및 학습용 회원 1번의 평점 조회 화면을 구현했습니다.

### 📝 작업 내용
- v5 조회 서비스와 TMDB 클라이언트 분리
- 공용 버튼의 비활성·로딩 상태 및 너비 옵션
- 닉네임·이메일 중복 확인과 입력 변경 시 결과 무효화
- 중복 문자열 기억, 이전 요청 응답 무시, dispose 후 갱신 방지
- 가입 버튼 상태 연동, 실제 가입 POST 없이 홈 이동
- 마이페이지에서 평점 화면 진입, 중앙 제목·뒤로가기·하단 탭 숨김
- 평점 Loading·Empty·Error·Success 상태 구현
- TMDB 상세 조회와 영화 정보 대체 표시
- 응답 모델·공용 버튼 자동 테스트 추가

### 🔍 리뷰 요청 사항
- 입력 변경 중 도착하는 응답 처리
- 평점 조회 실패와 영화 정보 조회 실패 구분
